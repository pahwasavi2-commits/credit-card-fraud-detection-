# 💳 Credit Card Fraud Detection

## 📌 Overview

This project focuses on analyzing credit card transactions to identify fraudulent activities using Exploratory Data Analysis (EDA). The dataset contains anonymized transaction information, allowing the identification of fraud patterns and transaction behavior.

The project aims to understand the characteristics of fraudulent transactions and provide insights that can help in building effective fraud detection systems.

---

## 🎯 Objectives

* Analyze transaction data.
* Identify fraud patterns.
* Study class imbalance.
* Detect anomalies and outliers.
* Perform correlation analysis.
* Generate insights for fraud detection.

---

## 🛠️ Technologies Used

---

## 📊 Analysis Performed

* Data Cleaning
* Missing Value Analysis
* Class Distribution Analysis
* Transaction Amount Analysis
* Time-Based Analysis
* Correlation Analysis
* Outlier Detection
* Fraud Pattern Analysis

---

## 📂 Dataset

The dataset contains:

* Time
* Amount
* V1–V28 anonymized features
* Class (0 = Genuine, 1 = Fraud)

---

## 📈 Key Insights

* The dataset is highly imbalanced.
* Fraudulent transactions show different behavioral patterns.
* Certain features contribute significantly to fraud detection.
* Outlier analysis helps identify suspicious transactions.
